# How to Contribute

We're always looking for people to help make Inkarr even better, there are a number of ways to contribute.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies:
   ```bash
   pnpm install
   ```
4. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development

To start the development server:

```bash
pnpm dev
```

## Making Changes

- Follow the existing code style and conventions
- Write clear commit messages
- Add tests for new features
- Update documentation as needed

## Building and Testing

```bash
# Build the project
pnpm build

# Run tests
pnpm test

# Lint code
pnpm lint
```

## Submitting a Pull Request

1. Push your changes to your fork
2. Create a Pull Request with a clear description of your changes
3. Reference any related issues
4. Wait for code review and feedback

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.

## Questions?

Feel free to open an issue to ask questions or discuss ideas.

Thank you for contributing to Inkarr!
